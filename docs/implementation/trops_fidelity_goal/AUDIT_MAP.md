## Deliberate plan choices beyond the feedback

- This phase completes historical source-mapped software. External SQL execution
  remains a separate milestone and cannot be inferred from synthetic verification.
- Versioned requests/bundles protect existing scientific identities and saved
  results when new source fields, outcomes and support context are added.
- A source profile's edited variants retain their deviations and cannot inherit
  its qualification badge.
- C scenarios use the same scored patients; they neither estimate population
  composition nor create extra independent observations.
- Six mechanism comparisons across four support strata and two profiles bound
  the next reference effort. New requests were frozen after adopting the historical
  source mapping; partial v2 runs cannot substitute for the 48 new references.
- Complete transition accounting separates direction changes from evidence
  gains/losses, including the C>=2 case with missing respiratory evidence.
