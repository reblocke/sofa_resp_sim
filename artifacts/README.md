# Artifacts

This directory holds small, checked-in validation evidence and historical
milestone summaries. It should not become a dumping ground for opaque outputs.

## Rules

Keep an artifact in git only when it is:

- small,
- reproducible or historically useful,
- safe for public version control,
- documented in the inventory below.

Do not commit PHI, patient-level raw extracts, restricted datasets, large raw
exports, or scratch files that cannot be regenerated or explained.

## Regeneration policy

- Prefer `uv run ...` commands for new or refreshed artifacts.
- Update this inventory in the same commit as any artifact addition, removal, or
  regeneration.
- If an artifact becomes obsolete but still useful for history, mark it
  `deprecated` instead of silently deleting it.

## Paired reference evidence workflow

The full paired bundles remain ignored under `local/references_v2/` and are
produced by `make experiments-reference`. After complete validation,
`scripts/summarize_experiment_references.py` creates compact source-linked tables
in `experiments_v2/`. The separate plotting command is
`uv run --group figures python scripts/plot_experiment_references.py`.
Generated figures require review of the exact PNG hash before acceptance. Current
review records are in the figure manifests; generation alone is not acceptance.

| File group in `experiments_v2/` | Generated by | Purpose and scope |
|---|---|---|
| `condition_summary.csv`, `paired_contrasts.csv`, `table_provenance.json` | `uv run python scripts/summarize_experiment_references.py` | Absolute and paired summaries of all 72 catalogue requests; source bundle, request and table hashes; 68 stochastic runs at N=2,000 and four deterministic episode runs at N=1 |
| `traces/*.csv` (12 files) | Same summarization command | Selected events and episodes for six prespecified generated patient-0 examples spanning E1–E6 and all four support strata; no observed-effect selection |
| `figures/*.svg`, `figures/*.png` (36 pairs), `figure_data_manifest.json` | Plotting command above | Primary-outcome absolute and paired figures for all 18 demonstrations, with source-table selection and image hashes |
| `FINDINGS.md` | `uv run python scripts/write_experiment_findings.py` | Prespecified-contrast readout, uncertainty and model limitations; not clinical validation |
| `INTERPRETATION.md` | Review of the source tables and rendered figures | Mechanism-specific interpretation, null results, ceiling effects and limits of inference |
| `rule_explorer/spo2_*.json`, `rule_explorer/measured_pao2_*.json`, `rule_explorer/cells.csv`, `rule_explorer/manifest.json` | `scripts/build_rule_explorer_evidence.py` | Eight deterministic grids containing 476 source-linked cells |
| `rule_explorer/figures/*`, `rule_explorer/figure_data_manifest.json` | `scripts/plot_rule_explorer_evidence.py` | Eight SVG/PNG grid pairs, with exact-image visual-review records |

The compact collection is approximately 18 MB. Full per-patient reference bundles
and execution logs remain local. `uv run python scripts/verify_experiment_evidence.py`
checks collection completeness, source hashes and current image-review records;
it does not establish clinical calibration or independent scoring equivalence.
